#Enterprise Warehouse Platform

##Overview

An enterprise-style Warehouse Management
PLatform built using DevOPs practices.

##Technology Stack

- Ubuntu Linux
- Python
- FastAPI
- PostgreSQL
- Redis
- Docker
- GitHub Actions
- Terraform
- Kubernetes
- Helm
- Prometheus
- Grafana

##Architecture

The platform will contain:

- Backend API
- Background Worker
- PostgreSQL Database
- Redis Cache
- CI/CD Automation
- Container Infrastructure
- Kubernetes Deployment
- Monitoring and Observability
